# Koopman dla jednego pełnego wektora

Badamy przewidywanie 384 liczb jednego tokenu RF-DETR. Dobór tokenu i modelu jest wcześniejszy niż ocena. Nie stosujemy PCA. Dane źródłowe pozostają w sąsiednim eksperymencie, a kod i wyniki tej nowej hipotezy są tutaj.

Uruchomienie: `F:/Python/python.exe test_jeden_wektor.py`, następnie `F:/Python/python.exe analiza.py` w tym katalogu. Protokół: PLAN.md. Stan: zakończony. Wyniki są w wyniki/, opis w WYNIKI_TEST.md i DIAGNOZA.md. Skrypt odmawia nadpisania ukończonego raportu. Dodatkowe odtworzenie zapisanych macierzy i ilustracji: `F:/Python/python.exe podsumowanie.py`.
