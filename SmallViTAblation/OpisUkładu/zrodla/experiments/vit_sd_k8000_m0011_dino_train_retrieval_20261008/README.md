# Wyszukiwanie naturalnych odpowiedników obrazów SD m0011

Eksperyment wyszukuje w istniejącym indeksie DINO 35 000 naturalnych klatek treningowych po pięć najbliższych obrazów dla każdego z 11 etapów interpolacji latentu.

Uruchomienie:

```powershell
F:\Python\3.13\python.exe retrieval.py
```

Wyniki są zapisywane w `outputs/latent_cel_do_obrazow/sd_k8000_m0011_dino_train_retrieval`.
