# schur_qr_jakobiany_mlp_20261024__10-03-40

Lokalnie, bez treningu i bez Edena. Rodzic: pomiar diagnostyk rzutu z sesji 2026-10-24 (okienko M).

## Cel

Dla każdego z 600 tokenów i każdego z 6 bloków MałegoViT policzyć pełny jakobian 192 × 192 pola MLP i scharakteryzować go
tak, jak w mechanice płynów charakteryzuje się tensor gradientu prędkości (Keylock 2018, „The Schur decomposition of the
velocity gradient tensor for turbulent flows”, J. Fluid Mech. 848, 876–905): rozkład Schura na część normalną i nienormalną,
rozkład S/Ω, niezmienniki Q i R; to samo dla kompresji 3 × 3 do rzutu sceny (J3 = P J Pᵀ) z klasycznym diagramem Q–R.
Porównanie narzędzie vs tło, korelacje z ciepłem głowy i normą skoku, seria 6 checkpointów (trend z treningiem; kontekst:
Fernando & Guitchounts 2026). Tylko definicje, tabele liczb i uwagi techniczne; bez wykresów i wniosków.

Hipoteza do sprawdzenia (z zadania, nie oceniana tutaj): trening instaluje gradient spektralny przez głębokość
(wczesne warstwy nienormalne i zdominowane obrotem, późne prawie symetryczne).

## Model, checkpointy, dane

- Model: MałyViT (`laser_app.compute.history.modul_modelu()`): łodyga CNN, 6 bloków timm z pre-LayerNorm, d = 192, MLP 192 → 768 → 192 z GELU (erf), 600 tokenów (zdjęcie 320 × 480, siatka 20 × 30).
- Historia: `LaserLatentSpaceApp/cache_uczenia/lasery/90f58d4f8b263d8b` (806 checkpointów, 1094 kroki/epokę); wagi `assets/MalyViT_35000_od_zera_s47/wagi/k<krok>.pt`.
- Checkpointy: 6 równo rozłożonych po **indeksie** historii (`np.linspace(0, K−1, 6)` → indeksy 0, 161, 322, 483, 644, 805): kroki 0, 6564, 21300, 36100, 50800, 65640 (epoki 0, 6, 19.5, 33, 46.4, 60). Krok 65640 = ostatni (obowiązkowy). SHA256 wag w `Kod_eksperymentu/pochodzenie.json`. Odstępy w krokach nie są równe, bo historia ma gęstsze checkpointy na początku.
- Tokeny narzędzia: `History.narz` po domyślnym `History.ustaw_etykiete()` (tryb „dotknięte”), opis: „obrys TR_0127_S1_P03 kl. 1 (cystotome), dotknięte: 17 łat” → 17 tokenów narzędzia, 583 tła. (Nie użyto `d['mapa'] > 0.5`; `mapa` zapisano w npz.)
- Ciepło głowy: sigmoid(`d['glowa'][12, :, 0]`) z `hist.podkroki` danego checkpointu (stan końcowy).
- Rzut sceny: P = `d['baza']['P_n']` (3 × 192, wiersze ortonormalne), wspólna baza `passage_store.wczytaj_baze(.../przejscia)` dla wszystkich checkpointów (jak w aplikacji).

## Procedura

1. `hist.podkroki(h.wagi, krok, h.rgb, baza=baza, lodyga=False)` (ładuje wagi, daje `glowa`, `baza`, `jak_n`), potem ręczna pętla po blokach, jak w `diagnostyki_rzutu.py`: wejście MLP bloku b to x_b = t + attn(LN₁ t).
2. Pole MLP F_b(x) = fc2(GELU(fc1(LN₂ x))) (skok x ← x + F). Jakobian dokładnie z wag w float64 na GPU:
   J = W2 · diag(GELU′(a)) · W1 · J_LN, J_LN = diag(γ/σ) · (I − 11ᵀ/C − x̂x̂ᵀ/C), GELU′(a) = Φ(a) + a φ(a).
3. Na CPU (12 procesów, BLAS jednowątkowy): zespolony Schur LAPACK `zgees` (bez wektorów Schura), SVD, wszystkie miary niżej. J3 = P J Pᵀ i te same miary dla 3 × 3.
4. Zestawienia: percentyle 10/50/90 po tokenach (wszystkie / narzędzie / tło) na blok, Spearman z ciepłem głowy i z ‖F‖, różnice narzędzie − tło (Mann–Whitney), klasy Q–R J3, mediany na blok w funkcji kroku.

## Definicje miar (n = 192 dla J, n = 3 dla J3; nazwy kolumn jak w plikach)

| kolumna | definicja |
|---|---|
| nJ | ‖J‖_F |
| nLam, nN | Schur zespolony J = Z T Zᴴ, T = Λ + N; nLam = ‖Λ‖_F = (Σ|λ_i|²)^½ (część normalna), nN = ‖N‖_F (część nienormalna, odchylenie Henriciego) |
| nN_henrici | (‖J‖_F² − Σ|λ_i|²)^½ (kontrola: = nN) |
| N_do_J, kappa | ‖N‖_F/‖J‖_F, ‖N‖_F/‖Λ‖_F |
| nS, nOm, Om_do_S | S = (J+Jᵀ)/2, Ω = (J−Jᵀ)/2: ‖S‖_F, ‖Ω‖_F, ‖Ω‖_F/‖S‖_F |
| trJ | tr J (w notacji Chonga i in. P = −tr J) |
| Q, R | A = J − (tr J/n) I; Q = −½ tr(A²), R = −⅓ tr(A³) |
| Q_S, Q_Om | Q_S = −½ tr(S_A²) = −½‖S_A‖_F² (S_A = (A+Aᵀ)/2), Q_Ω = +½‖Ω‖_F²; Q = Q_S + Q_Ω (kontrola: QS_plus_QOm_minus_Q) |
| nSA | ‖S_A‖_F |
| Q_Lam, R_Lam | μ_i = λ_i − tr J/n (wartości własne A); Q_Λ = −½ Re Σ μ_i², R_Λ = −⅓ Re Σ μ_i³ |
| Q_minus_QLam, R_minus_RLam | Q − Q_Λ, R − R_Λ. **Uwaga techniczna:** tożsamościowo 0, bo tr(A^k) = Σ μ_i^k (tr(T^k) zależy tylko od diagonali T, N jest ściśle górnotrójkątna); wartości ~1e-15 to błąd zaokrągleń. Q i R w całości pochodzą z widma; nienormalność wchodzi w ich rozbicie na S i Ω (wiersz niżej). Gdyby Q_Λ liczyć z λ_i samego J (nie A), różnica byłaby (tr J)²/(2n). |
| Q_S_Lam, Q_S_N, Q_Om_Lam, Q_Om_N | rozbicie Keylocka w bazie Schura (J rzeczywista ⇒ Jᴴ = Jᵀ): ‖S_A‖_F² = Σ(Re μ_i)² + ½‖N‖_F², ‖Ω‖_F² = Σ(Im μ_i)² + ½‖N‖_F²; Q_S^Λ = −½Σ(Re μ_i)², Q_S^N = −¼‖N‖_F², Q_Ω^Λ = +½Σ(Im μ_i)², Q_Ω^N = +¼‖N‖_F² (Q_S^N + Q_Ω^N = 0). Kontrola: resid_QS_keylock = Q_S^Λ + Q_S^N − Q_S |
| udzN_w_S2, udzN_w_Om2 | udział nienormalności w ‖S_A‖_F² i ‖Ω‖_F²: (½‖N‖_F²)/‖S_A‖_F², (½‖N‖_F²)/‖Ω‖_F² |
| n_re_dod, n_re_uj, n_zero, n_im | liczba λ z Re λ > τ, Re λ < −τ, |λ| ≤ τ, |Im λ| > τ (liczone wartości własne, nie pary); τ = 1e-6 · max(‖J‖_F, 1) |
| max_re, rho, max_im | maks Re λ, promień spektralny maks |λ|, maks |Im λ| |
| n_mod_gt1 | liczba |λ| > 1 + τ |
| n_1pl_gt1, max_mod_1pl | liczba |1 + λ| > 1 (wartości własne I + J, wzmocnienie zaburzenia w jednym podkroku x ← x + F; warunek 2 Re λ + |λ|² > 2τ), maks |1 + λ| |
| norm2_J, norm2_IpJ | ‖J‖₂, ‖I + J‖₂ (największa wartość osobliwa) |
| typ192 / typ3 | typ znakowy z niezerowych λ: 1 = wszystkie Re < 0 (stabilny), 2 = mieszane (siodło), 3 = wszystkie Re > 0 (niestabilny) |
| delta_QR3, klasa_QR3 (tylko J3) | Δ = 27R²/4 + Q³ z bezśladowej części A3; 0 = Δ>0, R<0: ognisko stabilne / rozciąganie (SFS); 1 = Δ>0, R>0: ognisko niestabilne / ściskanie (UFC); 2 = Δ<0, R<0: węzeł niestabilny / siodło / siodło (UNSS); 3 = Δ<0, R>0: węzeł stabilny / siodło / siodło (SNSS) (Chong, Perry & Cantwell 1990). Klasa dotyczy części bezśladowej; „stabilny/niestabilny” w nazwie klasy nie uwzględnia tr J3 |
| normF_surowe, normF_srodkowane | ‖F_b(x_j)‖ (prawdziwy skok MLP z biasem) i ‖F‖ w układzie środkowanym po tokenach (jak w aplikacji: (z − z̄) W2ᵀ) |

## Uwagi techniczne

- Zgodność: J3 = P J Pᵀ zgadza się z `jak_n` aplikacji do maks. błędu względnego ≤ 8.7e-7 (float32 aplikacji), F_surowe zgadza się z modułem timm do ≤ 4.6e-7 (wszystkie checkpointy, tabela „Kontrole numeryczne”). nN = nN_henrici, Q = Q_S + Q_Ω, rozbicie Keylocka: reszty ~1e-13.
- LayerNorm daje dwa kierunki zerowe J: 1 (dokładnie, |λ| ~ 1e-16) oraz x̂ (niezmienniczość skali, |λ| ~ ε/(σ²+ε) ~ 1e-8); następne |λ| ≥ ~4e-4. Stąd τ = 1e-6·max(‖J‖_F,1) i n_zero = 2 we wszystkich tokenach. Wcześniejsza próba z τ = 1e-9·‖J‖_F liczyła drugi kierunek raz jako zero, raz nie (odrzucona).
- Klasyfikacja Δ>0 dla J3 zgadza się w 600/600 tokenach z obecnością zespolonych λ w widmie J3 (kontrola).
- Mediany liczb całkowitych (n_re_dod itd.) są percentylami z interpolacją (np. 91.4).
- Spearman przy stałej miarze (np. n_mod_gt1 = 0 we wszystkich tokenach) oznaczony „–”.
- Odniesienie losowe (Ginibre, iid N(0,1)) dla miar bezwymiarowych w tabeli „Odniesienie”.
- Czas: przejście + jakobiany ~2–4 s, Schur/eig/SVD dla 3600 macierzy 192 × 192 ~29–35 s, 3 × 3 ~0.4 s na checkpoint (12 procesów); całość 6 checkpointów ~3.5 min.
