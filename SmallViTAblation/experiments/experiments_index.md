# Indeks eksperymentów

Rejestr prowadzony od 2026-10-20. Każdy agent dopisuje tutaj nowy eksperyment przy tworzeniu jego katalogu: pełną nazwę, odnośnik i krótki cel. Kontynuując ten sam eksperyment, aktualizuje istniejący wpis. Wcześniejsze eksperymenty nie zostały jeszcze zinwentaryzowane w tym indeksie.
