### 1. KRYTYCZNY FIX: LR Reset Bug w DETR Training
**Problem:** Learning rate był resetowany do initial_lr przy każdym resume checkpoint.

**Plik:** `Eden/Scripts/20kDataset_11.12.25/detr_train_optimized.py`

**Naprawa:**
```python
# PRZED (błędne):
for param_group in optimizer.param_groups:
    param_group['lr'] = args.lr  # Zawsze reset do initial!

# PO (poprawne):
if resume_epoch == 0:  # Tylko przy pierwszym starcie
    for param_group in optimizer.param_groups:
        param_group['lr'] = args.lr
else:  # Resume - zachowaj scheduler LR
    scheduler.step()  # Scheduler kontynuuje od ostatniego checkpointa
```

**Wpływ:** Teraz LR poprawnie się zmniejsza przy resume, zamiast skakać z powrotem do 1e-4.
