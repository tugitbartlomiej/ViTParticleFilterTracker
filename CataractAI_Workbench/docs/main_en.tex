\begin{abstract}
This document provides a comprehensive mathematical description of the
multi-feature dataset selection pipeline for training DETR-based surgical
tool detectors.  The pipeline combines four complementary feature groups
--- visual semantics (DINO), frequency content (Fourier), scene complexity
(SAM), and sample difficulty (EL2N) --- into a unified 43-dimensional
representation for diversity-aware selection via weighted $k$-means
clustering.  We provide theoretical and empirical justification for
incorporating Fourier-domain features, drawing on spectral bias theory,
frequency-enhanced DETR architectures, and coverage-oriented coreset
selection.  Empirical validation demonstrates that Fourier features exhibit
$3.4\times$ higher per-dimension importance than DINO embeddings, while the
selected 20,000-image subset preserves the spectral distribution of the
full 90,389-image pool (KS test, all $p > 0.35$).
\end{abstract}
